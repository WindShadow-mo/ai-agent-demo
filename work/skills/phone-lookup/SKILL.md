# Phone Lookup Skill

## 用途

当用户请求以下内容时，可查询电脑号码详情。

- 按姓名查电话号码
- 按电话号码反查姓名
- 查询电话号码详情，如国家/地区、运营商、类型、备注

且只能从以下引用文件查电话号码详情，并以其中数据为准
- ./reference/phone-number-doc.md

## 输入

支持以下形式：

- 姓名：如“李白”
- 电话号码：如“+86 138 0000 0000”
- 模糊描述：如“查一下李四的号码”

## 输出规则

1. 找到匹配记录时，输出：姓名、电话号码、国家/地区、运营商、类型、备注。
2. 只提供电话号码时，先反查姓名，再输出详情。
3. 未找到时，回复：“未在测试数据中找到该电话号码/联系人。”
4. 不得编造 ref 文件中不存在的号码或详情。
5. 所有数据均为测试数据，输出时提醒“请勿拨打”。

## 测试用例

- 输入：查张三的电话  
  预期：读取 ref 文件，返回张三记录。
- 输入：+1 555 010 0000 是谁  
  预期：返回李四记录。
- 输入：查不存在的人  
  预期：返回未找到。
